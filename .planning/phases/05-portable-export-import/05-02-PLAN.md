# Plan 05-02: `agent-memory export` — format v1 JSONL, streamed, atomic and private on disk

## Phase Goal

**As a** user, **I want to** export all my memories to a portable file and import them on another machine, **so that** my agent's memory moves with me — across machines, with no cloud sync.

This plan is the first half of that story: the user can run `agent-memory export` and get a versioned JSONL file — header, one record per memory, one record per link, no vectors — on stdout or atomically written to a private file.

<objective>
1. **Tracer:** define format v1 once (`export.rs`: `Record` enum + consts + module-doc spec, golden-tested), add `Store::export_rows` (ONE pooled connection, ONE read transaction: meta pin + counts, then memories ascending id, then links), add `MemoryService::export(out, version)` streaming one line per record through a boxed writer in one `spawn_blocking` hop, and wire `agent-memory export` to stdout. The end-to-end check is the real binary printing a valid header line on an empty database.
2. **Expansion:** `--output PATH` through `export_file::PendingExport` — `create_new` + mode 0600 temp in the target's directory, sync + rename after the stream is flushed, temp removed on failure.

Purpose: the on-disk contract (D-03..D-06) is frozen exactly once, in one Rust type, written by a path that cannot buffer the corpus or straddle two snapshots, and the file never exists in a world-readable or half-written state.
Output: `export.rs`, `Store::export_rows`, `ExportReport` + `MemoryService::export`, `Command::Export { output }`, `export_file.rs`, `tests/export_import.rs` (export half).
</objective>

## Interface contracts (established by this plan)

**`crates/agent-memory-core/src/export.rs`** (new; `pub mod export;` in lib.rs between `embed` and `import`)

```text
pub const FORMAT_NAME: &str = "agent-memory-export";
pub const FORMAT_VERSION: u32 = 1;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "record", rename_all = "lowercase", deny_unknown_fields)]
pub enum Record {
    Header { format: String, version: u32, exported_at: i64, embedding_model: String, embedding_dim: u32,
             schema_version: i64, agent_memory_version: String, exported_rows: u64, exported_links: u64 },
    Memory { key: i64, #[serde(rename = "type")] mem_type: String, content: String, tags: Vec<String>,
             source: Option<String>, scope: Option<String>, created_at: i64, last_accessed: i64,
             access_count: i64, expires_at: Option<i64> },
    Link   { from: i64, to: i64, kind: String, created_at: i64 },
}

pub struct ExportSnapshot { pub embedding_model: String, pub embedding_dim: u32, pub memories: u64, pub links: u64 }
pub enum ExportEvent { Snapshot(ExportSnapshot), Record(Record) }
```
- Field order on the wire = declaration order with `record` first (serde-verified in RESEARCH Pattern 1). `type`/`kind` are `String` so conversion runs through `MemoryType::try_from` / `LinkKind::try_from` in the importer (D-09).
- `exported_rows`/`exported_links` are the orchestrator's resolution 1: a cheap truncation check, decided now so it is inside v1 (`deny_unknown_fields` would reject it later).
- `ExportSnapshot`/`ExportEvent` are the store→service streaming protocol, not wire types (no serde derives needed).

**`Store::export_rows`** (`store/mod.rs`)

```text
fn export_rows(&self, visit: &mut dyn FnMut(ExportEvent) -> Result<(), MemoryError>) -> Result<(), MemoryError>;
```
Contract: one pooled read connection; one read transaction (`conn.unchecked_transaction()?`; fallback `execute_batch("BEGIN")` … `COMMIT`); emits exactly ONE `ExportEvent::Snapshot` first (meta pin + `count(*)` of `memories` and `memory_links`), then one `ExportEvent::Record(Record::Memory { .. })` per row of `SELECT id, mem_type, content, tags, source, scope, created_at, last_accessed, access_count, expires_at FROM memories ORDER BY id`, then one `ExportEvent::Record(Record::Link { .. })` per row of `SELECT from_id, to_id, kind, created_at FROM memory_links ORDER BY from_id, to_id, kind`. Rows are visited lazily from `query_map` — never collected into a `Vec`. The single snapshot is what makes a concurrent `link` unable to produce a dangling key (PITFALLS 5; the FK guarantees every endpoint is in the same snapshot). `embedding_dim` is TEXT in `meta` and is parsed to `u32`; a non-integer is `MemoryError::Internal("meta.embedding_dim is not an integer (…)")` — never a client error. `tags` decode with `serde_json::from_str::<Vec<String>>(..).unwrap_or_default()` (the `row_to_view` convention). `mem_type` and `kind` are passed through as the stored strings.

**`MemoryService::export`** (`service.rs`)

```text
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, serde::Serialize)]
pub struct ExportReport { pub memories: u64, pub links: u64 }

pub async fn export(&self, out: Box<dyn std::io::Write + Send>, agent_memory_version: String) -> Result<ExportReport, MemoryError>
```
`export` = `export_unredacted(..).await.map_err(|e| redact_storage_error("export", e))`. Body: `let now = self.clock.now();` then ONE `spawn_blocking` that moves `out`, `store`, `version`: on `Snapshot(s)` build `Record::Header { format: FORMAT_NAME.into(), version: FORMAT_VERSION, exported_at: now, embedding_model: s.embedding_model, embedding_dim: s.embedding_dim, schema_version: LATEST_SCHEMA_VERSION, agent_memory_version: version.clone(), exported_rows: s.memories, exported_links: s.links }`, record the counts, write it; on `Record(r)` write it; after `export_rows` returns, `out.flush()`. `write_line` = `serde_json::to_writer(&mut *out, &rec)` then `out.write_all(b"\n")`; any `serde_json::Error`/`io::Error` → `MemoryError::Internal(format!("export write failed: {e}"))` (crate-authored, passes redaction unchanged). `LATEST_SCHEMA_VERSION` is `crate::store::migrations::LATEST_SCHEMA_VERSION`.

**`crates/agent-memory/src/export_file.rs`** (new; `mod export_file;` in main.rs)

```text
pub struct PendingExport { temp: PathBuf, target: PathBuf, file: std::fs::File }
pub fn export_temp_path(target: &Path) -> PathBuf          // target.with_file_name("{name}.export-tmp-{pid}")
pub fn begin(target: &Path) -> std::io::Result<PendingExport>   // create_private(&temp)
impl PendingExport {
    pub fn writer(&self) -> std::io::Result<std::fs::File>  // self.file.try_clone()
    pub fn commit(self) -> std::io::Result<()>               // sync_all, then rename(temp, target); on rename error remove temp (best-effort) and return the error
    pub fn abort(self)                                       // best-effort remove_file(temp); warn via tracing on a non-NotFound error
}
#[cfg(unix)]     fn create_private(path) -> io::Result<File>  // OpenOptions write(true).create_new(true).mode(0o600) via std::os::unix::fs::OpenOptionsExt
#[cfg(not(unix))] fn create_private(path) -> io::Result<File> // same without mode; Windows ACL inheritance is the Phase 6 seam (DIST-03), mirroring config.rs::create_data_dir
```

| database (0700 dir, owner-only) → export file on disk | the corpus leaves the DB's protection; the file must be no looser than the DB |
| store read pool ↔ concurrent writers (MCP server, REST daemon) | WAL readers see a snapshot per transaction; two separate statements may straddle a write |
| service → CLI stdout/stderr | stdout carries the data stream; stderr carries the report and any error text |
