# Plan 05-03: `agent-memory import --from jsonl` — strict two-pass restore with key→id remapping

## Phase Goal

**As a** user, **I want to** export all my memories to a portable file and import them on another machine, **so that** my agent's memory moves with me — across machines, with no cloud sync.

This plan is the second half: the file written by plan 02 is read back on another machine — into an empty or an already-populated database — and every memory and link comes back with the right identity, idempotently, with expired rows skipped and counted, re-embedded locally by the sweep, and with every defect in the file refused as a client error before anything is written.

<objective>
1. **Tracer:** a pure, strict parser (`import/jsonl.rs::parse_jsonl`) that validates the whole file into typed records with 1-based line numbers; `MemoryService::import_jsonl` running the memories pass (expiry skip → `find_by_key` dedup → `insert_imported`, building `key → id`) and the links pass (`Store::link` through the map, counting created/duplicate/dropped); the `--from jsonl` CLI arm that parses before it opens the database and prints the six-count report plus the pending-embedding line. End-to-end check: the real binary exports an empty database and imports the file into a second database with an all-zero report.
2. **Expansion:** the kill-tests and the malformed-file table — overlapping rowids never attach phantom edges (PITFALLS 18), dedup-to-existing adjacency, in-file duplicates collapse, the expiry fixture with `links_dropped` (PITFALLS 19), pending → sweep → hybrid-searchable (criterion 3), header-only/zero-byte/file-order edges, hostile-input non-panic probes, and every D-11 rejection class naming its line.

Purpose: INTEROP-02 holds literally — idempotent, `embedding_status = 0`, expired skipped and counted, malformed rejected as client errors through the Phase 3 seam — and DIST-04's "export-local key remapping" is proven against a target whose rowids collide with the file's keys.
Output: `import/jsonl.rs`, `import/mod.rs` reword, `ImportReport` +4, `import_jsonl`, `clock_skew_message`, the `jsonl` CLI arm, the import half of `tests/export_import.rs`, one assertion in `tests/import.rs`.
</objective>

## Interface contracts (established by this plan)

**`crates/agent-memory-core/src/import/jsonl.rs`** (new; pure, no I/O)

```text
pub struct JsonlHeader { pub exported_at: i64, pub embedding_model: String, pub embedding_dim: u32,
                         pub schema_version: i64, pub agent_memory_version: String,
                         pub exported_rows: u64, pub exported_links: u64 }
pub struct JsonlMemory { pub key: i64, pub memory: ImportedMemory }   // last_accessed is validated, then dropped (D-10 refresh)
pub struct JsonlLink   { pub from: i64, pub to: i64, pub kind: LinkKind, pub created_at: i64 }
pub struct JsonlFile   { pub header: JsonlHeader, pub memories: Vec<JsonlMemory>, pub links: Vec<JsonlLink> }

pub fn parse_jsonl(text: &str) -> Result<JsonlFile, MemoryError>
```
Every rejection is `MemoryError::InvalidArgument(format!("line {n}: {msg}"))` (Display → `invalid argument: line 42: …`, the D-11 shape), built by a private `fn invalid_line(line_no: usize, msg: impl Display) -> MemoryError`.

Line 1 — two-step header (RESEARCH Pattern 2): a private lenient `#[derive(Deserialize)] struct HeaderProbe { record: String, format: String, version: serde_json::Value }` WITHOUT `deny_unknown_fields`, checked in this order with these messages — parse failure → `missing or invalid header ({serde message})`; `record != "header"` → `first record must be the header`; `format != FORMAT_NAME` → `format must be 'agent-memory-export' (got '{format}')`; `version` not an unsigned integer → `version must be a positive integer (got {value})`; `version == 0` → `version must be >= 1 (got 0)`; `version > FORMAT_VERSION` → `file is format version {v} but this binary reads up to version {FORMAT_VERSION} — upgrade agent-memory`; only then the strict `serde_json::from_str::<Record>(line)` which must be `Record::Header { .. }` → `JsonlHeader`.

Lines 2.. — `text.lines().enumerate()`, `line_no = idx + 1`: empty/whitespace-only or first non-whitespace byte not `{` → `expected a JSON object`; `from_str::<Record>` error → its message verbatim under the line prefix; `Record::Header` → `duplicate header`; `Record::Memory` → `MemoryType::try_from(mem_type.as_str())` (its message re-wrapped under the line prefix), `content.trim().is_empty()` → `content must be a non-empty string`, duplicate `key` → `duplicate memory key {key}`, else push `JsonlMemory { key, memory: ImportedMemory { content, mem_type, tags, source, scope, created_at, access_count, expires_at } }`; `Record::Link` → `LinkKind::try_from(kind.as_str())` (already `InvalidArgument` naming the allowed set — re-wrap under the line prefix), `validate_link_endpoints(from, to)` (self-link → `from_id and to_id must differ`), push `JsonlLink`. After the loop: each link's `from`/`to` must be a memory key seen anywhere in the file (order-independent) else `link key {k} does not appear in the file` at that link's line; `memories.len() != exported_rows` → `line {last}: file declares {exported_rows} memory records but contains {n}`; likewise for links. A zero-byte or header-less file fails at line 1.

**`MemoryService`** (`service.rs`)

```text
pub struct ImportReport { imported, skipped_duplicates,                       // existing
                          skipped_expired, links_imported, links_skipped_duplicates, links_dropped }  // new, all usize
pub const CLOCK_SKEW_TOLERANCE_SECS: i64 = 3600;
pub(crate) fn clock_skew_message(exported_at: i64, now: i64) -> Option<String>   // Some(..) iff exported_at > now + CLOCK_SKEW_TOLERANCE_SECS
pub async fn import_jsonl(&self, file: JsonlFile) -> Result<ImportReport, MemoryError>   // = import_jsonl_unredacted(..).map_err(|e| redact_storage_error("import", e))
```
`import_jsonl_unredacted`: `let now = self.clock.now();` `if let Some(msg) = clock_skew_message(file.header.exported_at, now) { tracing::warn!("{msg}"); }` — NO embedder call anywhere. ONE `spawn_blocking` hop over `store`: `let mut map: HashMap<i64, i64>`; **pass 2** for each `JsonlMemory { key, memory }`: `if memory.expires_at.is_some_and(|t| t <= now) { skipped_expired += 1; continue; }` (no map entry — the D-10 import rule, `<=`); `match store.find_by_key(memory.source.as_deref(), memory.mem_type, &memory.content)? { Some(id) => { skipped_duplicates += 1; map.insert(key, id); } None => { let id = store.insert_imported(memory, now)?; imported += 1; map.insert(key, id); } }`; **pass 3** for each `JsonlLink`: `match (map.get(&from), map.get(&to)) { (Some(a), Some(b)) => match store.link(*a, *b, kind, created_at)? { LinkOutcome::Linked { created: true } => links_imported += 1, LinkOutcome::Linked { created: false } => links_skipped_duplicates += 1, LinkOutcome::NotFound { .. } => links_dropped += 1 }, _ => links_dropped += 1 }`. Per-record transactions (the `insert`/`link` shape): a storage fault mid-pass leaves a partial import that a re-run completes idempotently — validation (pass 1, in `parse_jsonl`) is the all-or-nothing gate. Skew message text: `export header exported_at {exported_at} is {delta}s ahead of this machine's clock ({now}); check both clocks — expiry and freshness of imported rows are computed against this machine`.

**CLI** (`main.rs`, `run_import`)

`match from.as_str()`: `"gsd-state"` → the existing body unchanged (incl. `default_scope_for`); `"jsonl"` → if `scope.is_some()` bail `--scope applies only to --from gsd-state (a jsonl file carries each memory's own scope)`; `let file = agent_memory_core::import::jsonl::parse_jsonl(&text).with_context(|| format!("validating {}", path.display()))?;` BEFORE `resolve_db_path`/`SqliteStore::open`; then open store + service like today; `let report = service.import_jsonl(file).await.context("importing")?;` `println!("imported: {}, skipped duplicates: {}, skipped expired: {}, links imported: {}, links skipped duplicates: {}, links dropped: {}", …)` and `println!("{} rows pending embedding — the sweep backfills them on the next serve/serve-rest start (128 per tick)", report.imported)`; any other value → `unsupported --from value {from:?} (supported formats: gsd-state, jsonl)`. The `from` flag doc becomes "Source format. Supported: gsd-state (a GSD .planning/STATE.md file), jsonl (an agent-memory export)."; the `Import` variant doc mentions both and the dedup key.
