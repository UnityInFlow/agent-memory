## Phase Goal

**As a** user, **I want to** export all my memories to a portable file and import them on another machine, **so that** my agent's memory moves with me — across machines, with no cloud sync.

This plan closes the two `human_verification` items in 05-VERIFICATION.md (status `human_needed`, 32/33) so the re-verifier can mark the phase `passed` without a human: (1) the 05-02 backstop truth about one WAL snapshot gets a held-out race test, and (2) the "on the other machine" step of the user story is actually run against the live Ollama on this host and recorded.
