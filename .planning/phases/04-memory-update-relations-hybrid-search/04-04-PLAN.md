## Phase Goal

**As an** agent, **I want to** update existing memories, link related ones, and get hybrid keyword+semantic recall, **so that** my memory stays current and connected and I find the right memory even when the phrasing differs.

This plan delivers the "hybrid keyword+semantic recall" slice (SEARCH-04/05): after Task 1 an agent's searches are rank-fused and decay-aware; after Task 2 every degrade/error path and the wire contract are locked.

<objective>
Ship decay-aware hybrid search: service-level RRF fusion (k=60, duplicate ids sum) over two pure-relevance oversampled legs — the existing distance-ordered KNN leg and a new bm25-ordered `keyword_candidates` leg — with a post-fusion multiplicative decay blend (SEARCH-05), `search_mode: "hybrid"` on the unchanged SearchOutcome envelope, and v1.0-identical keyword degradation when the embedder is down (SEARCH-04).

Purpose: the phrasing no longer has to match — an exact-keyword hit and a semantic paraphrase hit both surface, and fresh memories still win.
Output: hybrid fusion in `MemoryService::search`, locked by tests/hybrid.rs golden fixtures plus the degrade decision table.
</objective>
