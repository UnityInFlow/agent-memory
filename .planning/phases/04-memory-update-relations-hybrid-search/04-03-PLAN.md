## Phase Goal

**As an** agent, **I want to** update existing memories, link related ones, and get hybrid keyword+semantic recall, **so that** my memory stays current and connected and I find the right memory even when the phrasing differs.

This plan delivers the "link related ones" slice end-to-end (MCP-07): after Task 1 an agent can link/unlink memories with typed relations that cascade cleanly; after Task 2 search/list can expand 1-hop neighbors on demand.

<objective>
Ship flat typed relations on the migration-0003 schema from plan 04-01: `memory_link`/`memory_unlink` with the closed three-kind vocabulary (D-01), idempotent duplicates + self-link rejection + clean not-found (D-02), directed storage with bidirectional natural-label expansion (D-03), opt-in `expand_links` on search/list with trimmed summaries (D-04/D-05), no neighbor bumps (D-06), and the fixed MAX_EXPANDED_LINKS cap (D-07).

Purpose: an agent's memories become a connected working set — supersession chains and causes stay navigable without a graph/entity model.
Output: link/unlink/expansion on both transports, cascade proofs, envelope byte-compat proof, locked by tests/relations.rs.
</objective>
