# Plan 02-03: GSD STATE.md Import (Idempotent)

## Phase Goal

**As a** developer running AI agents across editors and tools, **I want to** install agent-memory with one command and have it recall my memories by meaning — falling back to keyword search when Ollama is absent, reachable over REST, and able to import my GSD project state, **so that** every agent session starts with the right context, fully locally with no cloud.

This plan delivers the interop slice: one command loads a GSD project's accumulated decisions, blockers, and todos into memory (INTEROP-01).

<objective>
Add `agent-memory import --from gsd-state <path> [--scope <s>]`: a tolerant parser in core (`import/gsd_state.rs`) maps STATE.md sections to typed `NewMemory` drafts, `MemoryService::import` dedups against the store on the `(source, mem_type, content)` key and batch-embeds new items in ONE Ollama call (best-effort), and the CLI prints an import report to stdout (sanctioned — MCP-05 applies only to `serve`).

Purpose: INTEROP-01 — a GSD project's accumulated context becomes agent memory in one command, re-runnable without duplication (phase success criterion 4).
Output: `import/` module, `Store::exists`, `MemoryService::import` + `ImportReport`, `Import` subcommand, fixture + green `tests/import.rs`.
</objective>

## Interface contracts (established by this plan)

- `agent_memory_core::import::gsd_state::parse_gsd_state(text: &str, scope: Option<String>) -> ParsedStateFile` where `ParsedStateFile { drafts: Vec<NewMemory>, skipped: usize }`. Pure function, no I/O — the CLI reads the file.
- Section → type mapping (RESEARCH Pattern 5, verified against this repo's real `.planning/STATE.md`): `### Decisions` bullets → `MemoryType::Decision`; `### Blockers/Concerns` bullets → `MemoryType::Constraint`; `### Pending Todos` bullets → `MemoryType::Todo` (skip `None yet.` placeholder); `## Deferred Items` table data rows → `MemoryType::Todo` with extra tag `deferred`.
- Every draft: `source = Some("gsd-state".into())`, `tags` contains `"gsd"`, `scope` from the argument, `ttl_secs = None`.
- `Store::exists(&self, source: &str, mem_type: MemoryType, content: &str) -> Result<bool, MemoryError>` — parameterized `SELECT 1 … LIMIT 1` dedup probe.
- `MemoryService::import(&self, drafts: Vec<NewMemory>) -> Result<ImportReport, MemoryError>` with `ImportReport { imported: usize, skipped_duplicates: usize }` (derive Debug + Serialize).
- CLI: `Import { #[arg(long)] from: String, path: PathBuf, #[arg(long)] scope: Option<String> }`; only `gsd-state` is a valid `--from` value in v1.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → parser | untrusted/messy STATE.md file content crosses into typed drafts |
| imported content → downstream agents | memory content is later injected into agent contexts via search results |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-20 | Tampering | parse_gsd_state / exists / insert | mitigate | tolerant scanner (skip + count, never execute); dedup SELECT and inserts fully parameterized; content treated strictly as data |
| T-02-21 | Elevation (prompt-injection carrier) | imported memory content consumed by agents | transfer/accept | content is never executed or interpreted by agent-memory; composes with the ecosystem injection-scanner (documented, no in-phase code — RESEARCH Security Domain) |
| T-02-22 | Denial of Service | oversized items / huge files | mitigate | MAX_IMPORT_CONTENT_BYTES = 8192 per item with skip-count; whole-file size accepted (local, user-owned CLI input) |
| T-02-23 | Repudiation | provenance of imported rows | mitigate | every imported row carries source = "gsd-state" + tag "gsd" + scope — auditable and bulk-removable |
| T-02-SC | Tampering | new dependencies | mitigate | none added — hand-rolled scanner per RESEARCH (pulldown-cmark deliberately avoided) |
</threat_model>
